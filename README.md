# Trilok Neupane — Next.js Portfolio

A responsive portfolio starter built with the Next.js App Router, React, CSS, and lucide-react icons.

## Requirements

- Node.js 20.9 or later (recommended for current Next.js)
- npm

## Run locally

```bash
npm install
npm run dev
```

Visit http://localhost:3000.

## Production build

```bash
npm run build
npm start
```

## Before publishing

- [ ] Replace `YOUR_EMAIL@example.com` in `app/page.js`.
- [ ] Replace the generic GitHub link with your actual GitHub profile URL.
- [ ] Verify the current job title, start date, and responsibilities at NepalExportingIT.
- [ ] Verify the BR CODEX internship title, dates, tasks, and technologies.
- [ ] Verify BCA institution, completion status, year, and GPA against official records.
- [ ] Verify DevOps training provider, duration, dates, and completed topics.
- [ ] Confirm the listed academic projects and their technologies/features.
- [ ] Add actual repository/demo links for projects you have completed.
- [ ] Keep planned DevOps projects labelled as planned until they are complete.
- [ ] Add your resume PDF to `public/` and link it from the page.
- [ ] Test all links and the mobile layout.

## Deploy to Vercel

1. Push this folder to a GitHub repository.
2. Import that repository in Vercel.
3. Vercel should detect Next.js automatically.
4. Deploy and verify the production URL.

This starter does not include a contact form backend or a resume PDF yet. The email link is a `mailto:` placeholder until you replace it.
